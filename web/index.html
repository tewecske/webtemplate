Scala + ScalaJS + Vite Template

The same "save a note, read its full history back from SQLite" demo, built three different ways. Each page lets you pick which backend (Cask or ZIO HTTP) it talks to.

Variant A Vanilla JavaScript Hand-written .js, plain fetch + DOM Variant B TypeScript Typed .ts, same feature Variant C Scala.js Compiled from Scala via sbt

Run npm run dev from the repo root to bring up both backends, the Scala.js watcher, and this Vite dev server together.
